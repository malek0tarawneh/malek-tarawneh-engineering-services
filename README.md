# Civil & Transportation Engineering Services Website

A clean public website prototype for civil and transportation engineering services, built to organize professional service presentation, client request intake, and engineering workflow communication.

## Project Overview

This project presents a professional digital hub for civil and transportation engineering support. The website is designed to help visitors understand the available services, review the service workflow, and submit a structured engineering request.

The project focuses on practical engineering support areas such as traffic and transportation studies, trip-generation analysis, QA/QC documentation, infrastructure reporting, technical deliverables, and data-driven engineering workflows.

## Main Features

- Professional homepage for engineering services
- Clear service sections for civil and transportation engineering support
- Structured client-request form
- Service workflow explanation
- Sample deliverables section
- Clean thank-you page after request submission
- Netlify Forms support for request intake
- Responsive design for desktop and mobile viewing
- Professional branding and public-facing content

## Service Areas

- Traffic and transportation studies support
- Trip generation and traffic data organization
- Infrastructure project support
- Engineering documentation and technical reports
- QA/QC and site inspection documentation
- Engineering data analysis
- Excel, Google Sheets, and Python-supported engineering workflows

## Technology Used

- HTML
- CSS
- JavaScript
- Netlify Forms
- Static website deployment

## Purpose

The purpose of this project is to present a clean and professional online identity for engineering services and to demonstrate how a simple digital workflow can support engineering communication, service requests, and project intake.

## Project Status

This is an early public version. Future improvements may include stronger project tracking, secure file upload, client authentication, automated quotation workflow, and expanded engineering case studies.
